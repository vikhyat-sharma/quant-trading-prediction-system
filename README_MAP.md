## 💡 Key Concepts Quick Reference

### 5 Prediction Algorithms
- **SMA**: Trend identification (50-60% confidence)
- **EMA**: Responsive trends (55-65%)
- **Momentum**: Overbought/oversold detection (55-60%)
- **Mean Reversion**: Ranging markets (50-65%)
- **ENSEMBLE**: Weighted combination (65-75% - recommended)

### 3 Authentication Roles
- **User**: Standard access
- **Admin**: Extended access
- **SuperAdmin**: Full system access

### 10+ Portfolio Metrics
